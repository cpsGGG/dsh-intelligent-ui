# Documentation images

`overview.png` and `diagram-dark.png` are captures of the actual IUI React components rendered by `docs/demo.jsx` with the project's synthetic examples. They contain no user conversation, account, filesystem, or desktop capture.

The standalone demo uses `docs/demo-markdown.jsx` as a small demonstration adapter. Inside DSH, the host's native MarkdownText and math renderer are used instead. These are component previews, not screenshots of a native DSH session.

The example content and these captures are original project material under the root MIT license. Generated preview JavaScript, CSS, and font files are ignored by Git; run `npm run demo` to rebuild them locally.
